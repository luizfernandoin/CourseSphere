# Evidências de Testes e Varreduras

Este diretório contém os relatórios e logs brutos gerados durante o ciclo de avaliação de segurança e confiabilidade:

- `sast/`: Relatórios do Semgrep, Bandit, Gitleaks.
- `sca/`: Relatórios de dependências (pip-audit, npm audit, Trivy).
- `dast/`: Relatórios de varredura dinâmica (OWASP ZAP).
- `balanceamento/`: Logs e scripts provando o balanceamento de carga do Nginx entre as instâncias do backend.
